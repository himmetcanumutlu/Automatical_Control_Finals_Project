# Unity Automatic Control Simulation

A lightweight Unity-based simulation project for testing automatic control loops and feedback mechanisms.

## Features
- Interactive control system simulation
- Real-time parameter adjustment and data visualization
- Simple and clean C# script architecture

## Getting Started
1. Open this project in **Unity** (recommended version: 2021.3 LTS or newer).
2. Open the main simulation scene located in `Assets/Scenes/`.
3. Press **Play** in the Unity Editor to run the simulation.
